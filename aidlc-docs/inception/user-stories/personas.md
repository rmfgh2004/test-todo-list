# Personas

## P-001 계획을 실행으로 옮기려는 개인 지식 근로자

### 프로필

- **이름**: 김민서
- **역할**: 여러 종류의 집중 업무와 짧은 행정 업무를 병행하는 개인 지식 근로자
- **환경**: 평일 데스크톱 브라우저에서 주간 계획을 만들고 이동 중 모바일에서 확인·완료
- **기술 숙련도**: 일반적인 웹 생산성 도구에 익숙하지만 복잡한 설정은 원하지 않음
- **데이터 범위**: 한 기기에서 개인 업무만 관리하며 계정과 협업 기능은 필요하지 않음

### 목표

1. 해야 할 일을 빠르게 기록해 잊지 않는다.
2. 목록의 할 일을 실제로 가능한 시간에 배치한다.
3. 이미 잡힌 일정과 충돌하지 않는 현실적인 주간 계획을 만든다.
4. 주중에 계획을 쉽게 수정하고 완료 진행을 확인한다.

### 좌절과 위험

- 할 일 목록이 길어져도 언제 해야 할지 알 수 없다.
- 일정이 겹치거나 하루에 지나치게 많은 업무를 넣기 쉽다.
- 드래그가 실패했는지 저장됐는지 알 수 없는 인터페이스를 신뢰하지 않는다.
- 작은 화면에서 전체 주간 그리드를 억지로 축소한 UI는 읽기 어렵다.
- 자동 재배치가 조용히 기존 계획을 바꾸는 것을 원하지 않는다.

### 핵심 행동

- 제목과 예상 시간만으로 먼저 할 일을 만든다.
- 주간 시작 시 미배치 목록을 보고 중요한 항목부터 타임테이블에 배치한다.
- 충돌이 나면 두 일정을 비교하고 새 할 일을 다음 빈 시간으로 옮기거나 취소한다.
- 업무가 끝나면 완료하고 남은 미배치 시간과 할 일을 확인한다.
- 목록 보기에서 완료·미완료와 배치 상태를 필터링해 누락을 점검한다.

### 사용 컨텍스트

#### 데스크톱 집중 계획

- 백로그와 주간 그리드를 동시에 비교한다.
- 마우스 드래그와 상세 시간 입력을 함께 사용한다.
- 이전 주·다음 주를 오가며 마감일을 기준으로 배치한다.

#### 모바일 확인 및 빠른 조정

- 선택한 하루의 타임라인과 별도 백로그 패널을 확인한다.
- 할 일을 완료하거나 직접 날짜·시간을 입력해 배치한다.
- 전체 주간 표를 축소한 화면 대신 읽을 수 있는 일 단위 흐름을 기대한다.

#### 키보드 및 보조 기술

- 모든 명령을 Tab, Enter, Space, Escape로 수행할 수 있어야 한다.
- 드래그 대신 날짜와 시간을 선택하는 동일 기능의 대체 경로가 필요하다.
- 충돌, 저장 성공·실패, 완료 변경을 `aria-live` 알림으로 인지한다.
- 초점 위치와 상태를 색상 외 텍스트·아이콘으로도 구분한다.

### 성공 신호

- 3분 안에 새 할 일을 만들고 주간 시간에 배치해 완료할 수 있다.
- 충돌 상황에서 기존 데이터가 어떻게 처리될지 선택 전에 이해한다.
- 모바일과 키보드만으로도 핵심 여정을 중단 없이 끝낸다.
- 주간 화면을 보고 남은 가용 시간과 미배치 업무를 빠르게 판단한다.
