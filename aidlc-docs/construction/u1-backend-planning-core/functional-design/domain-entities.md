# U1 Domain Entities

## Aggregate Boundary

`Task` is the only mutable aggregate root. It owns content, status and an optional `ScheduleSlot`.
`AuditEvent` is an append-only record created by application orchestration and has no update lifecycle.

## Task Aggregate (FR-003, FR-004, FR-006, FR-008, FR-009)

| Field | Domain Type | Required | Constraint |
|---|---|---|---|
| id | TaskId(UUID) | yes | immutable, server generated |
| title | TaskTitle | yes | 1~120 chars, text only |
| description | TaskDescription | no | <= 2,000 chars, text only |
| priority | Priority | yes | LOW/MEDIUM/HIGH |
| estimate | EstimateMinutes | yes | 15~840, multiple of 15 |
| dueDate | LocalDate | no | Asia/Seoul date semantics |
| status | TaskStatus | yes | TODO/COMPLETED |
| schedule | ScheduleSlot | no | valid daily window and alignment |
| version | long | yes | optimistic concurrency, >= 0 |
| createdAt | Instant | yes | immutable |
| updatedAt | Instant | yes | nondecreasing |

### Domain Operations

- `create`, `updateContent`, `schedule`, `unschedule`, `setCompletion`.
- Operations return a new valid aggregate state or typed domain failure.
- No public setter exposes partial invalid state.
- `delete` is an application/repository operation because it ends aggregate lifecycle.

## Value Objects

### TaskId

- wraps UUID and rejects null/malformed transport values.
- equality by UUID value.

### TaskTitle

- canonical value trims outer whitespace.
- preserves internal whitespace and Unicode.
- never contains trusted HTML semantics.

### TaskDescription

- optional text with length bound.
- not stored in audit events or logs.

### EstimateMinutes

- positive integer 15~840 and divisible by 15.
- provides `addTo(LocalTime)` only after window validation context is supplied.

### Priority

- enum LOW, MEDIUM, HIGH.
- sort rank HIGH=0, MEDIUM=1, LOW=2 without ordinal persistence coupling.

### ScheduleSlot (FR-006, FR-007)

| Field | Type | Constraint |
|---|---|---|
| date | LocalDate | within requested planning week for candidate search |
| start | LocalTime | 08:00~21:45, 15-minute aligned |
| end | LocalTime | derived, start < end <= 22:00 |

- half-open interval `[start, end)` on one local date.
- end is derived from Task estimate when created for mutation.
- equality includes date, start and end.

### WeekRange

- constructed only from a Monday.
- represents `[weekStart, weekStart + 7 days)`.
- supplies bounded day iteration for next-slot search.

### TaskVersion

- nonnegative long supplied by the client on mutation.
- adapter maps it to JPA optimistic version; domain does not depend on JPA annotations.

## Typed Outcome Models

### ScheduleResult

```text
Scheduled(taskView)
Conflict(existingSlot, proposedSlot, nextCandidate?, requestId)
```

- conflict contains only safe task identifiers/titles needed for local UI and time values.
- no persistence entity, SQL or stack information crosses the boundary.

### DomainFailure

```text
ValidationFailure(code, fieldErrors)
TaskNotFound(taskId)
ScheduleConflict(conflictData)
StaleTaskVersion(taskId, currentVersion)
```

- application/web layers map these exhaustively to safe HTTP responses.

## AuditEvent (FR-013)

| Field | Type | Constraint |
|---|---|---|
| eventId | UUID | immutable, generated |
| taskId | UUID | immutable reference value; no FK required after task delete |
| action | AuditAction | allowlisted enum |
| actor | String | fixed `local-user` for MVP |
| requestId | String | bounded opaque ID |
| occurredAt | Instant | immutable |
| changedFields | Set<AuditField> | allowlisted structural names |
| structuralSummary | AuditSummary | optional non-sensitive values |

### Allowed Structural Summary

- priority, estimateMinutes, dueDate, status.
- schedule date/start/end.
- version before/after.
- never title, description, DB path/key, raw payload or exception text.

## Persistence Adapter Model

### TaskJpaEntity

| Column | Mapping | Notes |
|---|---|---|
| id | UUID primary key | generated by application |
| title | varchar(120) not null | text only |
| description | varchar(2000) nullable | not logged |
| priority | varchar(16) not null | explicit enum string |
| estimate_minutes | integer not null | check 15~840 and modulo 15 |
| due_date | date nullable | local date |
| status | varchar(16) not null | explicit enum string |
| schedule_date | date nullable | all schedule columns null or all present |
| start_time | time nullable | second precision rejected at boundary |
| end_time | time nullable | derived and persisted for indexed overlap query |
| version | bigint not null | JPA optimistic version |
| created_at | timestamp with time zone | UTC instant |
| updated_at | timestamp with time zone | UTC instant |

### AuditEventJpaEntity

- independent table without cascading delete from task.
- no update repository method and database permissions/application port expose insert/query only.
- changed fields stored as bounded structured JSON or normalized child rows; implementation decided in NFR design.

### Database Constraints

- status/priority/action check constraints or validated enum mapping.
- estimate range/modulo check.
- schedule all-null/all-non-null check and start < end.
- indexes: `(schedule_date, start_time, end_time, status)`, `(status, due_date, priority)`, audit `(task_id, occurred_at)`.
- Flyway owns schema; Hibernate schema auto-generation disabled outside tests.

## Query Projections

### TaskView

- all user-visible task fields plus version and timestamps.
- no persistence or audit internals.

### WeeklyPlanView

- `weekStart`, `weekEndExclusive`.
- scheduled `TaskScheduleItem[]`.
- unscheduled incomplete `BacklogItem[]`.
- server time policy metadata: zone=`Asia/Seoul`, slotMinutes=15, dayStart/end.

### TaskListItem/Page

- summary fields required by FR-010.
- page metadata: page, size, totalElements, totalPages, stable sort.

### SafeApiError

- code, generic message, requestId, optional allowlisted fieldErrors.
- no exception class, stack, path, SQL or framework version.

## Entity Relationship Text Alternative

Task optionally embeds one ScheduleSlot and has no child lifecycle outside the aggregate. Application
commands create zero or one append-only AuditEvent per material change. AuditEvent stores TaskId as an
immutable reference value so physical Task deletion cannot remove history. Query projections are derived
read models and are never persisted as independent mutable entities.
