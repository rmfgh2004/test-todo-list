# U2 Code Generation Step 3 Clarification Questions

답변은 아래 `[Answer]:` 뒤에 선택지 문자를 입력한다.

## Question 1

드롭 시각이 두 15분 경계의 정확한 중간인 경우(예: `08:07:30`) 어느 쪽으로 스냅할까?

A) 다음 경계로 올림한다. `08:07:30`은 `08:15`가 된다. 일반적인 반올림과 일치하며 권장한다.

B) 이전 경계로 내림한다. `08:07:30`은 `08:00`이 된다.

C) 정확한 중간값은 유효하지 않은 드롭으로 거부하고 사용자가 다시 선택하게 한다.

D) Other (please describe after [Answer]: tag below)

[Answer]: A

**Decision:** 정확한 중간값은 다음 15분 경계로 올린다. 일반적인 반올림 규칙과 일치하고,
포인터가 가리킨 시각보다 이른 위치로 작업을 이동시키지 않는 결정론적 동작을 제공한다.
