# 03. 아키텍처 방침

## 1. 아키텍처 스타일

- 선택: React SPA + Spring Boot 계층형 모듈러 모놀리스 + embedded H2.
- 결정 근거: 단일 사용자 로컬 MVP에서 독립 배포 서비스보다 단순한 실행과 강한 트랜잭션,
  빠른 테스트가 중요하다.
- 기각: 마이크로서비스는 운영 부담이 과도하고, 프론트 전용 로컬 저장소는 Java 백엔드
  요구와 데이터 무결성 검증을 충족하지 않는다.

## 2. 경계 나누기

- 프론트 단위: app shell, timetable, task management, API client.
- 백엔드 단위: task 도메인, schedule 도메인, persistence, web/security adapter.
- 통신: 프론트와 백엔드는 `/api/v1` JSON REST로 동기 통신한다.
- 공유 금지: 프론트가 DB에 직접 접근하지 않으며 controller가 repository를 직접 호출하지 않는다.
- 데이터 쓰기 주체는 백엔드 application service 하나로 제한한다.

## 3. 데이터

- 데이터 소유권: 백엔드 task/schedule aggregate가 단독 소유한다.
- 일관성 모델: 생성, 수정, 배치, 충돌 판정과 완료는 단일 DB 트랜잭션에서 강한 일관성.
- 스키마 변경: Flyway 순차 버전 SQL, 적용된 마이그레이션 수정 금지.
- 보존·삭제: 사용자가 삭제한 할 일은 본 데이터에서 제거하고 변경 감사 레코드는 유지한다.
- 개발 DB: H2 AES 파일 암호화, 키는 환경 변수로 주입하고 저장소에 커밋하지 않는다.
- 테스트 DB: 테스트별 인메모리 H2로 격리한다.

## 4. 계층 규칙

- 의존 방향: web/persistence adapter → application → domain.
- domain은 Spring, JPA, HTTP와 UI 프레임워크에 의존하지 않는다.
- 외부 접근은 명시적 port/interface를 경유한다.
- 계층 위반은 패키지 구조 테스트와 리뷰에서 차단한다.

## 5. 비기능 요구사항 기준선

| 항목 | 목표 | 측정 방법 |
|---|---|---|
| 응답 지연 | 로컬 데이터 1,000건에서 API p95 300ms 이하 | 통합 성능 테스트 |
| 초기 화면 | 개발 머신 기준 2초 이내 사용 가능 | Playwright 측정 |
| 가용성 | 로컬 프로세스 실행 중 요청 성공률 99.9% | 통합 테스트와 오류 로그 |
| 확장성 | 할 일 10,000건에서도 주간 조회가 페이지·기간 필터로 제한 | 데이터셋 테스트 |
| 비용 상한 | 유료 서비스 없이 로컬 실행 | 의존성 및 인프라 검토 |

## 6. 보안

- 인증·인가: 인증 없는 단일 사용자이며 API는 loopback origin만 허용한다.
- 비밀값: DB 암호화 키는 환경 변수로만 주입하고 `.env`와 DB 파일은 gitignore한다.
- 최소 권한: 로컬 프로세스는 프로젝트 데이터 디렉터리 외 파일에 접근하지 않는다.
- 전송: 원격 배포 시 TLS 1.2 이상과 HSTS를 필수화하며 로컬 개발은 loopback으로 제한한다.
- 입력: 요청 크기, 문자열 길이, 날짜·시간 형식, enum을 allowlist로 검증한다.
- 출력: CSP, nosniff, frame deny, referrer policy를 설정하고 외부 스크립트를 사용하지 않는다.
- 남용 방지: API 속도 제한, 안전한 전역 예외 처리, 요청 ID를 적용한다.
- 공급망: lockfile, Maven 버전 고정, 취약점 검사, SBOM을 CI에서 생성한다.

## 7. 관측성

- 로그: JSON 구조화 로그, request ID, 민감정보 금지.
- 메트릭: 로컬 health endpoint와 요청 성공·실패·지연 메트릭.
- 추적: HTTP 요청 ID를 프론트 오류 메시지와 백엔드 로그에 연결한다.
- 장애 확인: health → 브라우저 네트워크 → request ID 로그 → DB 파일 접근 순서.

## 8. 배포

- 환경: local, test, production-ready 설정 프로필을 분리한다.
- 방식: 첫 릴리스는 로컬 실행 스크립트와 빌드 산출물까지만 제공한다.
- 롤백: Git 태그와 H2 백업 파일 복원 절차를 문서화한다.
- IaC: 현재 범위 밖이며 클라우드 배포를 추가할 때 별도 설계 승인을 받는다.
