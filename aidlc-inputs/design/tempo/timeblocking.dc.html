1a 주석
키보드 조작
Tab 좌측 목록 → 그리드 순서로 이동. 그리드 진입 시 오늘·다음 빈 슬롯에 포커스.
← → 하루 단위 이동 · ↑ ↓ 15분 단위 이동
Shift+↑ ↓ 블록 길이 15분씩 조절(최소 15분)
Enter 확정 · Esc 취소하고 원위치
Space 좌측 카드 집기 / 놓기 (드래그 대체 경로)
포커스 표시
모든 인터랙티브 요소: outline: 2px solid #4f46e5; outline-offset: 2px. 마우스 클릭 시에도 유지(:focus-visible 기준). 예시는 주 이동 ‹ 버튼.
스크린리더
그리드 role="grid", 열 = 요일, 행 = 15분 슬롯. 블록은 role="gridcell".
블록 낭독: “보고서 작성, 9월 1일 월요일 오전 9시부터 11시까지, 2시간, 우선순위 높음.”
빈 슬롯 낭독: “월요일 오후 1시 15분, 비어 있음.”
Radix 매핑
주 이동 = 일반 버튼 / 블록 클릭 시 상세 = Popover / 일정 편집 = Dialog / 뷰 전환(주·일) = Tabs / 우선순위 변경 = Select.

1c 주석
화면 요소
고스트 블록: 2px dashed accent + 시각 라벨. 소요시간(1h 30m)에 비례한 높이 90px.
대상 열 강조: 좌우 2px accent 보더 + raised 배경. 나머지 열 블록은 opacity 0.6.
간격 가이드: 위 블록과 2h, 아래 블록과 30m을 dashed 선 + 수치로 표기.
상단 가용 시간은 배치 후 예상값(11h 00m, −1h 30m)으로 미리 갱신.
키보드 조작
Space 카드 집기 → 좌측 목록에 “이동 중” 자리 유지
← → 요일 이동 · ↑ ↓ 15분 이동
Shift+↓ 길이 +15분 · Shift+↑ −15분
Enter 이 위치로 확정 · Esc 취소, 카드는 목록 원위치
스크린리더 (aria-live)
polite — 이동할 때마다: “화요일 오후 2시, 1시간 30분. 앞뒤 2시간·30분 비어 있음. 놓을 수 있습니다.”
polite — 길이 조절: “1시간 45분으로 변경.”
polite — 잔여 시간 변경: “이번 주 남은 가용 시간 11시간.” (연속 이동 시 300ms 디바운스, 마지막 값만 낭독)
polite — 취소: “배치를 취소했습니다. 보고서 초안 검토, 미배치 목록으로 돌아감.”
Radix 매핑
드래그는 Radix 밖(포인터 이벤트 + 커스텀 훅). 확정 결과 알림 = Toast(“화요일 14:00에 배치됨 · 실행 취소”).

3중 인코딩 (색 + 아이콘 + 텍스트)
색: danger #fca5a5 보더·라벨 / 아이콘: ⚠ / 텍스트: “겹침”, “놓을 수 없음”, “이 시간대에 ‘보고서 작성’이 있습니다”

충돌 블록과 새 블록을 좌우로 나눠 둘 다 보이게 유지(가리지 않음).
키보드 조작
경고 상태에서도 이동 가능: ↑ ↓ 15분, ← → 요일 — 겹침이 해소되면 경고 즉시 사라짐
Shift+↑로 길이를 줄여 빈 구간에 맞출 수 있음
Enter 기본 동작 = “11:00로 밀어 배치” · Tab 세 버튼 순회 · Esc 취소
Popover 열려 있는 동안 포커스는 Popover 내부에 갇힘(Radix 기본), 닫히면 원래 블록으로 복귀
스크린리더 (aria-live)
assertive — 겹침 발생 시: “겹침. 이 시간대에 보고서 작성이 있습니다. 오전 9시부터 11시까지. 1시간 30분 겹침. 밀어 배치, 겹쳐 두기, 취소 중 선택하세요.”
polite — 겹침 해소: “겹침 없음. 월요일 오전 11시부터 12시 30분까지 놓을 수 있습니다.”
polite — 잔여 시간 변경: “이번 주 남은 가용 시간 11시간.” 겹침 상태에서는 확정 전이므로 낭독하지 않음(현재 12h 30m 유지).
같은 문구 반복 시 재낭독되도록 메시지 끝에 보이지 않는 카운터 유지.
Radix 매핑
경고 = Popover(블록 앵커, role="alertdialog" 성격 시 Dialog로 승격) / 확정 후 결과 = Toast + 실행 취소 / 반복 규칙 편집 = Dialog + Select.
