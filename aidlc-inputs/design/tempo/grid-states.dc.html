스크린리더 (aria-live)
assertive: “저장하지 못해 되돌렸습니다. 팀 회의 준비는 월요일 오전 9시부터 11시까지, 원래 자리입니다. 화요일 10시 30분에는 API 설계 리뷰가 먼저 저장되었습니다.”
polite: “이번 주 남은 가용 시간 12시간 30분, 변경 없음.”
polite 재배치 성공 시: “팀 회의 준비, 화요일 낮 12시부터 1시 30분까지 저장됨. 남은 가용 시간 11시간.”
블록 자체의 aria-label에도 “되돌려진 블록”을 포함해, 알림을 놓쳐도 포커스 시 알 수 있게.
